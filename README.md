# Emoji Stash!

## Description

A simple repository for storing emoji (any images, really) that can be used in Projects, Issues, PRs, etc. on GitHub and possibly a multitude of other places, as well.

## Usage

### Markdown

To use an image in a Markdown file, you can use the following syntax:

```markdown
![:sadcat:](https://github.com/iodeslykos/emoji-stash/blob/main/emoji/sadcat.png?raw=true)
```

The above will render the following image with the alt text `:sadcat:`:

![:sadcat:](https://github.com/iodeslykos/emoji-stash/blob/main/emoji/sadcat.png?raw=true)
